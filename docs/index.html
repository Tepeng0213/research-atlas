SCIENTIFIC BOUNDARIES

Designed to show what is known—and what is missing.

A finished workflow is not the same as a validated scientific result. Research Atlas reports its assumptions and input requirements alongside calculations.

Prototype status

Docking scores are not measured binding affinity. Enumerated analogs are not proven improvements. Retrosynthesis suggestions need chemist review. A cocrystal candidate requires experimental confirmation. The current application runs locally with SQLite and one worker; this portfolio page does not host the interactive service.
